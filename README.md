# Stadium Rent Expert

臺北市體育局場地租借的輔助工具。目前的設定是溪洲〔福和〕河濱公園壘球場 B 面；要換場地、日期或時段，修改各腳本開頭的設定即可。

| 工具 | 用途 | 網站 |
|---|---|---|
| `userscript/stadium-rent-expert.user.js` | **場地預約**：依規定分批勾選時段、填資料 | https://vbs.sports.gov.taipei |
| `userscript/stadium-lottery.user.js` | **年度場地抽籤登記**：勾選整個抽籤期間的時段、填資料 | https://vbs.sportdraw.com.tw/lottery |
| `check.js` | 用指令查空檔，不需要登入 | https://vbs.sports.gov.taipei |
| `book.js` | 舊版預約程式（Playwright），**已無法送出**，見文末說明 | — |

兩支腳本都在你平常使用的 Edge 裡、透過篡改猴（Tampermonkey）執行。腳本負責勾選與填表；**登入驗證碼、Cloudflare 驗證、最後的送出按鈕都由你自己操作**。

## 安裝篡改猴與腳本（只要做一次）

1. 在 Edge 外掛程式商店安裝「**篡改猴**」（Tampermonkey，作者 Jan Biniok，綠色圖示）。
2. 到 `edge://extensions`，打開左側的「**開發人員模式**」。新版篡改猴要開這個才能執行腳本；如果篡改猴的詳細資料頁有「允許使用者指令碼」開關，也要打開。
3. 點工具列上的篡改猴圖示 → **建立新腳本**，刪掉預設內容，貼上腳本的全部內容，按 Ctrl+S 存檔。預約和抽籤各建一個腳本，兩支可以同時安裝，各自只在自己的網站上執行。
4. 之後要改設定，在篡改猴的編輯畫面修改腳本開頭的 `CONFIG`，存檔後重新整理網頁。更新腳本時，把整份內容換成新版即可。

打開對應網站後，右下角會出現腳本的面板，有「開始」「暫停」「清除紀錄」三個按鈕，以及執行紀錄。

## 場地預約腳本

`userscript/stadium-rent-expert.user.js`，用在 https://vbs.sports.gov.taipei 。

### 設定

```js
id2nd: 295,                  // 壘球場
id3rd: 285,                  // B 面（A=280, C=286）
from: '2026-11-01', to: '2026-12-31',  // 申請期間
weekdays: [1, 2, 3, 4, 5],   // 星期幾：0=週日, 1=週一 ... 6=週六
daysOfMonth: [16, 31],       // 每月幾號到幾號：[16, 31] 是下半月，整個月填 [1, 31]
hours: [19, 20, 21],         // 19:00–22:00，每個數字代表一小時
form: { type, deduct, sport, eventName, eventDescription, peopleAll },  // 活動資料
```

### 體育局登記限制（腳本會自動遵守）

| 限制 | 腳本的處理 |
|---|---|
| 單一帳號單日登記 4 小時 | `hours` 超過 4 小時，按「開始」時提示錯誤，不會執行 |
| 只開放 8–12、13–17、18–22 時 | `hours` 含 12 點或 17 點，按「開始」時提示錯誤 |
| 單週登記上限 16 小時 | 超過的日期略過 |
| 單月上限平日 10 日、假日 2 日 | 超過的日期依日期先後略過；國定假日依網站標示算假日 |

### 使用

1. 打開網站並登入（輸入驗證碼）。
2. 按面板的「**開始**」。腳本會先查詢時段，略過已被訂走、已過期、不開放或超過上限的日期，並在面板列出原因。
3. 每個月開一張申請單：腳本切到指定場地、逐月勾時段、填活動資料、按「直接申請租借」、勾「我同意場地注意事項」。**勾選時請不要操作頁面。**
4. 到確認頁時，等 Cloudflare 驗證完成（需要時輸入簡訊驗證碼），核對內容後按「**確認申請**」。
5. 申請完成後，腳本記下訂單編號，3 秒後自動開始下一個月。

- 只勾到部分時段的日期會整天取消，不會送出不完整的時段。
- 「暫停」可以隨時停止，之後按「開始」會從中斷的地方接續。已申請成功的日期會被記住，重新開始時自動跳過，也會算進每週、每月的上限。「清除紀錄」會清掉這些紀錄。
- 腳本只記得它自己申請過的日期。同一個月份如果另外手動訂過，要等網站在勾選時擋下，腳本才會略過那些日期。
- 申請送出後要等審核，通過後會寄 Email 通知，再到會員專區的「租借紀錄」線上繳費，逾期會被取消。

## 年度場地抽籤登記腳本

`userscript/stadium-lottery.user.js`，用在 https://vbs.sportdraw.com.tw/lottery 。

### 設定

```js
mainVenue: '溪洲[福和]河濱公園',      // 和網站「主場地」選單上的文字一樣
venue: '壘球場 B面',                   // 和網站「子場地」欄的文字一樣
from: '2027-01-01', to: '2027-06-30',  // 登記期間
weekdays: [1, 2, 3, 4, 5],             // 週一到週五
daysOfMonth: [16, 31],                 // 每月下半月
block: 18,                             // 18:00–22:00
form: { eventName, eventDescription, peoples },  // 活動資料
```

- 抽籤網站的非網球場地一次要登記 **4 小時**，只有 8–12、13–17、18–22 三種時段，所以 `block` 只能填 8、13 或 18。
- 每月平日、假日的額度由網站在勾選時檢查。超過額度、已被占用或你已登記過的時段，腳本會略過並在面板列出原因。

### 使用

1. 打開網站並登入（輸入驗證碼）。
2. 按面板的「**開始**」。腳本會進入「新增預定抽籤」、選主場地、打開子場地的「選擇時段」、逐月勾選、按「確認」和「下一步」、填活動資料。**勾選時請不要操作頁面。**
3. 到最後一步時，等頁面下方的 Cloudflare 驗證完成，核對內容後按「**送出**」。
4. 完成後畫面會顯示預定號碼，面板也會記下來。所有時段都在同一張登記單裡。

網站沒開放登記時，面板會顯示「目前未開放抽籤登記」並停止。抽籤結果請到網站的「場地抽籤登記結果」查看。

## 用指令查空檔：check.js

不用登入，直接查詢預約網站上指定時段的狀態，以及場地目前開放預約到哪個月份。

1. 到 https://nodejs.org 安裝 **LTS** 版 Node.js。
2. 在這個資料夾開 PowerShell，執行：

   ```powershell
   npm install
   npm run check
   ```

設定在 `config.js`：`id3rd`、`from`、`to`、`weekday`（只能填一個星期幾）、`hours`。`zerossl-intermediate.pem` 是用來補上網站缺少的中繼憑證，請保留。請不要頻繁執行，手動查詢或間隔 10 分鐘以上即可。

## 舊版預約程式：book.js（已無法使用）

`book.js` 用 Playwright 開瀏覽器自動預約。Playwright 控制的瀏覽器會被 Cloudflare 判定為自動化，在確認頁出現「驗證失敗」，**無法送出申請**。它也還沒套用體育局的每月、每週限制。請改用上面的場地預約腳本。

`book.js` 會從 `.env` 讀取帳號密碼（格式見 `.env.example`），並把登入狀態存在 `browser-profile` 資料夾。這兩個都含有你的帳號資訊，已列在 `.gitignore`，不要提交或分享給別人。

## 出錯時

面板會顯示錯誤原因並暫停。把面板和網頁畫面截圖下來，就能據此修正腳本。
