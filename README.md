# 福和河濱壘球場 B 面預約小幫手

- `check.js`：查空檔，不需要登入。
- `book.js`：自動分批申請。網站規定每張單最多 10 個平日，程式會自動拆成好幾張單，逐張勾時段、填資料、送出。

要訂的場地、日期、時段、活動資料都在 `config.js` 修改。

> **注意：** `book.js` 用 Playwright 控制的瀏覽器會被 Cloudflare 判定為自動化，出現「驗證失敗」而無法送出申請。實際申請請改用下面的 Tampermonkey 腳本。

## Tampermonkey 腳本（建議使用）

`userscript/stadium-rent-expert.user.js` 在你平常使用的 Edge 裡執行：

- **腳本負責：** 分批（每張最多 10 天）、切到指定場地、逐月勾時段、填活動資料、按「直接申請租借」、勾同意事項、申請完成後自動開始下一批。
- **你負責：** 登入、Cloudflare 驗證（通常會自動通過）、需要時的簡訊驗證碼、每張單按一次「確認申請」。

### 安裝（只要做一次）

1. 在 Edge 外掛程式商店安裝「**篡改猴**」（Tampermonkey，作者 Jan Biniok，綠色圖示）。
2. 到 `edge://extensions`，打開左側的「**開發人員模式**」。新版 Tampermonkey 要開這個才能執行腳本；如果篡改猴的詳細資料頁有「允許使用者指令碼」開關，也要打開。
3. 點 Edge 工具列上的篡改猴圖示 → **建立新腳本**，刪掉預設內容，把 `userscript/stadium-rent-expert.user.js` 的全部內容貼上，按 Ctrl+S 存檔。
4. 要改日期、時段、活動資料，在篡改猴的編輯畫面修改腳本開頭的 `CONFIG`，存檔後重新整理網頁。

### 使用

1. 打開 https://vbs.sports.gov.taipei 並登入，右下角會出現「Stadium Rent Expert」面板。
2. 按面板上的「**開始**」，腳本會跳到預約頁開始勾選。勾選時請不要操作頁面。
3. 到確認頁時，面板會提示你：等 Cloudflare 驗證完成、核對內容，然後按「**確認申請**」。
4. 申請完成後，腳本會記下訂單編號，3 秒後自動開始下一批。

- 「暫停」可以隨時停止，之後按「開始」會從中斷的地方接續。
- 已申請成功的日期會被記住，重新開始時會自動跳過。「清除紀錄」會清掉這些紀錄。
- 出錯時面板會顯示原因並暫停。截圖面板和畫面傳給我即可修正。

## Windows 安裝（只要做一次）

1. 到 https://nodejs.org 下載並安裝 **LTS** 版 Node.js。
2. 把這個資料夾放到電腦上，例如 `C:\fuhe-booking`。
3. 開啟 PowerShell：

   ```powershell
   cd C:\fuhe-booking
   npm install
   ```

   程式預設使用 Windows 內建的 Edge。如果打不開，再執行 `npx playwright install chromium`。
4. 把 `.env.example` 複製一份，改名為 `.env`，填入帳號和**新密碼**。
5. 打開 `config.js`，確認活動資料：活動名稱、說明、人數。

## 使用

```powershell
npm run check   # 查空檔，並顯示目前開放預約到哪個月份
npm run book    # 自動分批申請
```

### 你要做的

- 登入時輸入**圖形驗證碼**並按「登入」。
- 如果網站要求**簡訊驗證碼**，在瀏覽器按發送並輸入收到的碼。
- Cloudflare 真人驗證通常會自動通過。萬一出現需要點選的方塊，點一下就好。

### 程式自動做的

1. 把日期拆成每張最多 10 天。
2. 每張單：切到 B 面 → 逐月勾選時段 → 填活動資料 → 按「直接申請租借」→ 勾「我同意場地注意事項」→ 等驗證完成 → 按「確認申請」。
3. 已被訂走或還沒開放的日期會略過，不佔名額。只勾到部分時段的日期會整天取消，不會送出。
4. 申請成功的單會記在 `orders-log.txt`。重跑時會自動跳過這些日期，所以中途失敗可以直接再執行一次。

`config.js` 的 `confirmBeforeSubmit` 預設是 `true`：每張單送出前會在 PowerShell 停下來，按 Enter 才送出。第一次使用建議保留，確認填的資料都正確後再改成 `false`，之後就會全自動送出。

如果某張單出錯，程式會把畫面存到 `debug` 資料夾，把裡面的檔案傳給我就能修正。

申請送出後要等審核，通過後會寄 Email 通知，再到會員專區的「租借紀錄」線上繳費。

## 注意

- `.env` 和 `browser-profile` 裡有你的密碼和登入狀態，不要分享給別人。
- 請不要用程式頻繁查詢，手動執行或間隔 10 分鐘以上即可。
